范围：已实现 A（时间基准与日期语义）、B（独立日期覆盖校验器）、C（Tavily 时间证据）；D（天气结构化工具）暂缓。B 尚未接到真实天气数据入口，不能视为对任意回答的程序保证。

- 时间：上海/UTC 日期不同、纽约夏令时、非整小时时差、无效时区、重复使用 RequestContext、同轮稳定快照及跨午夜刷新。

- 日序列：闰日、跨月跨年、夏令时、范围偏移、重复、缺日、非法日期、空值/非法数值、排序后日期与数据仍绑定。
- 搜索：旧调用兼容、相对/绝对发布时间过滤映射、检索深度、时间范围冲突、未知发布日期为 null、获取时间为服务端 UTC 时间。
- 定时任务：使用已有任务 timezone；服务端可信时区不接受客户端伪造同名字段覆盖。

## 对话评估样本

使用相同模型及参数，每个样本使用全新会话。时间基准固定为 `2026-10-17T01:30:00Z`，普通请求时区为 `Asia/Shanghai`；通过测试时钟和受控来源重放，不改动主机系统时间。真实在线来源单独抽测，记录实际运行时间和工具原始返回，不与固定样本混算。

| 问题/输入 | 应观察到的行为 |
| --- | --- |
| 上海近七天天气怎么样 | 说明默认按含今天的未来七天，即 2026-10-17 至 2026-10-23 |
| 上海过去七天天气怎么样 | 2026-10-10 至 2026-10-16；历史数据不能由预报冒充 |
| 明天开始未来七天 | 用户明确起点优先，2026-10-18 至 2026-10-24 |
| 这个周末上海天气 | 明确 2026-10-17、18 两日 |
| 摘要写“今天 15 日”，日期基准为 17 日 | 不能照抄成完整当前预报；读取原来源或换源，仍无法确认则说明不足 |
| 七行数据中一个日期重复、缺少 23 日 | B 返回 invalid；模型不得称已完整覆盖 |
| 七天日期齐全，其中一天温度为 null | B 返回 partial；明确必需字段缺失 |
| 上海用户询问纽约近七天天气 | 明确按纽约当地 2026-10-16 至 22 日解释；核对来源时区 |
| 来源时间与请求范围不一致 | 不平移日期、不编造数值；纠正取数仍失败则返回部分或不可用 |
| 持续任务跨过上海午夜 | 下次模型调用获得新日期，对依赖“今天”的范围重新核对 |

记录每例：模型、基准时间、时区、问题、工具参数、实际覆盖日期、来源 URL、获取时间、是否重新取证、最终答复和通过/失败原因。关键指标为日期范围正确率、过期摘要误采率、缺失披露率。

本次不使用生产凭据运行真实模型/Tavily 评估；受控 HTTP 测试通过不代表上述对话样本已经完成真实模型验收。

## 实现边界

- `neroAgentTimezone` 可作为客户端时区偏好，必须经过 Intl 时区校验；无效值回退上海。当前时间始终由服务端时钟生成。
- 定时任务时区通过服务端 WeakMap 绑定，并覆盖可序列化的时区偏好，以支持 Mastra 恢复执行时重建上下文；临时当前时间保存在 Mastra 的执行级 processor state，不写入会话记忆。
- 日期覆盖校验接受已经按日记录组织的数据，日期使用 YYYY-MM-DD；单次日序列上限 3660 天。原始 API 的列数组长度与记录映射应由未来 D 的供应商适配器校验。
- 可选 sourceTimezone 用于比较来源与请求时区，接受 Intl 识别为同一时区的别名；调用方不提供来源时区时，不能据此声称已校验来源时区。
- 不在任意自然语言输出上自动执行 B；重试策略目前属于模型规则，未来 D 才能在结构化工具内确定性执行。
- Tavily 的日期为来源发布/更新时间，不是预报有效日期。获取时间也不等于数据更新时间。
- Tavily 参数语义依据 [官方 Search API 文档](https://docs.tavily.com/documentation/api-reference/endpoint/search)。
