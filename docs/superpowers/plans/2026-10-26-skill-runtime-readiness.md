# Skill 运行环境检查 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 在当前工作区逐项执行。

**Goal:** 管理端导入、编辑及发布技能时可看到真实环境检查结果，并阻止不满足条件的脚本版本发布。

**Architecture:** 保留现有 ZIP、草稿、权限和发布指针；扩展 skill-runtime.json v2。独立检查服务使用固定探测程序和正式任务初始化逻辑，在无宿主挂载的临时沙箱检查依赖。报告绑定内容与环境指纹，短时缓存；发布自动复检并沿用 revision 并发保护。

**Tech Stack:** TypeScript、Dockerode、React、Node test、Vitest。

**Spec:** 本次会话已批准的七部分实现方案。

## Global Constraints

- 不执行上传包中的探测脚本，不自动安装依赖，不改变旧发布版与会话 pin。
- 无声明但有脚本不能声称可用；基础设施故障不能误报缺依赖。
- 检查使用正式任务的 venv、环境变量及镜像，固定 UID、只读根目录、禁用网络。
- 保留当前工作区已有改动，不部署线上、不自动提交。
