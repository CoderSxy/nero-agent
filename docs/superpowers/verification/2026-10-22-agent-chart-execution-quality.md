实现位于当前 checkout（用户明确要求），未创建 worktree，未推送或部署。已有 MessageList.tsx / tool-row.css 改动未覆盖。

## 实现与边界

- 高置信纯图表任务仅开放取数和必要澄清工具，默认严格 JSON 的 echarts 围栏；显式 HTML、导出、附件、技能及混合操作保留对应能力。
- 缺失/无效配置最多定向修正一次，不重跑成功取数。仍失败时持久化失败说明并在 UI 提示。
- 历史以消息/调用 ID 协调；运行中保留新 delta，结束后有限同步，旧 pending/result 不能覆盖较新的实时结果/错误。
- 同目标状态连续两次失败提示调整，三次收尾。纯图表最多八次主模型调用，加一次无工具修正；即使 provider 无视工具限制也不会持续请求。到限使用本地失败响应保留进度，不伪造模型成功。
- OM 压缩删除原始用户/工具消息后，run 内交付方式、原始目标摘要和失败计数仍保留；新用户消息重置。
- 主模型、工具、首 token、首有效图表配置、回答完成与记忆周期分开记录。本地预算响应不算付费模型调用。没有修改 memory 模型或阈值。
- 已决定的 ECharts/HTML 格式问题由平台直接说明，不反复挂起让用户选择；城市、数据和权限等其他问题仍使用原生 ask_user。
