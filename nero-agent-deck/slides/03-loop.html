工作闭环

不是问答结束，
而是下一次开始。

一次会话里，外部信息被带进来，文件被写下去，记忆留下来，任务按周期再回来。四件事不是四个产品，而是一条路径。

01

查

Tavily 搜索与网页读取，把外部资料带进当前上下文。

SEARCH / FETCH
02

写

在工作区里查找、读取、精确编辑；每次写入都带版本校验。

GLOB / GREP / EDIT
03

记

会话记忆与线程隔离，下一次回来还能接上上一次的上下文。

MEMORY / THREAD
04

跑

定时任务在独立线程执行；暂停、恢复、日志都留在管理页。
