# nero-agent brand spec

## 资产

- 名称：NERO AGENT / nero-agent。
- 官方 vector logo：仓库内没有独立 SVG/AI 文件。界面截图中的 N 方块与 NERO / AGENT 字样作为视觉证据；方向稿用排版字标重建，不使用第三方品牌资产。
- 产品截图：`assets/screenshots/`，来源 `docs/screenshots/skill-ui-20261020/`。

## 色彩

- 界面主色：近黑 `#17171A`（按钮、主要文字）。
- 界面底色：`#F7F8F9` / `#FFFFFF`。
- 品牌渐变：紫色到蓝色，截图取样约 `#7C5CFC → #4E9BFF`。
- 方向稿会从这些颜色里取样，不额外发明“AI 紫”。深色方向使用石墨黑 + 信号绿，紫色只作为品牌小面积记忆点。

## 字体

- 中文正文：Hiragino Sans GB / Heiti SC（本机可用）。
- 中文展示：Songti SC（本机可用）。
- 西文与数字：Avenir Next / Helvetica Neue / SF Mono / Menlo。
- 不使用需要联网加载的字体，保证离线渲染一致。

## 语气

- 中文优先，技术标识保留英文。
- 句子短，动词开头，少形容词。
- 不编造用户量、客户、融资、性能基准或价格。
- 不把“AI”当视觉装饰；用真实界面、真实能力与边界说话。
