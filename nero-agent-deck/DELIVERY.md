# NERO AGENT · 产品介绍 deck

## 成品

打开 `NERO-AGENT.html`。11 页，1920×1080，A 方向「控制台」。

- 浏览器全屏：直接演示，滚动翻页。
- 打印 / 导出 PDF：浏览器打印，纸张 1920×1080，页边距 0，勾选背景图形。
- 分页源文件：`slides/01-cover.html` … `slides/11-closing.html`
- 演示索引：`index.html`（支持键盘翻页、概览墙）
- 方向选择记录：`direction-approved.md`

## 内容

01 封面 · 把一次对话，变成持续的工作
02 产品判断 · 聊天框很多，能留下来的工作台很少
03 工作闭环 · 查 / 写 / 记 / 跑
04 界面 · 一个屏幕，三个工作面
05 工作区 · 文件属于工作区，写入可验证
06 定时任务 · 不用记得回来，它自己回来
07 技能 · 把一套做法，变成可复用的能力
08 模型目录 · 公共 / 私有，Key 不出服务端
09 架构 · Mastra 在中间，数据在两侧，沙箱在下层
10 边界 · 默认关闭，显式开启
11 收束 · 它不是更会聊天，而是更能把事做完

## 说明

PDF 没在这台机器上生成：Chrome 155 和 Firefox 的 headless 实例在 macOS 26.6 下都异常退出（SIGABRT）。HTML 成品是完整的；用你自己的浏览器打开后打印即可得到矢量 PDF。没有使用假数据、客户案例或性能基准。
